Recovery codes

Recovery codes let you regain access when a password is lost or a phone is gone. Generate a full set in the grouped format most systems expect — with look-alike characters left out so they survive being read out loud or retyped.

Using these codes

  • Recovery codes are single use: a system should accept each one exactly once and then discard it.
  • The grouped format and the character set here match what most services issue, so the codes are easy to print, read and type back in.
  • Store the set apart from the device it recovers — a printed page, a password manager's notes or a safe. Replace the whole set once you have used a few.
