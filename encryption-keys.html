AES

Encryption keys

Raw random key material for AES-128, AES-192 and AES-256, ready to paste into a key manager. These are true random bytes — not passphrases stretched into a key — exported as Base64, Base64 URL-safe or hex.

Using these keys

  • AES expects exactly 16, 24 or 32 random bytes. A text string of a similar length is not equivalent — this generator produces the real key material.
  • Keep keys in a key manager or secrets vault, never in a repository, a config file or a chat message.
  • Use a separate key per environment or per tenant, and decide how you will rotate before you need to.
