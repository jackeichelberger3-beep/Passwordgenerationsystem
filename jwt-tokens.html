JWT tokens

A JSON Web Token is a compact, self-contained credential: a header and a payload of claims, signed with a secret so any service can verify it without a database lookup. Build one here with real claims — subject, issuer, audience, role and expiry — signed with HMAC-SHA256, 384 or 512.

Using these tokens

  • The signature covers the header and payload exactly as they are encoded, so editing either part later invalidates the token.
  • Claims are readable by anyone holding the token — they are signed, not encrypted. Never put a password, card number or personal data in them.
  • Keep the lifetime short and rotate the signing secret on a schedule. A leaked secret lets an attacker mint tokens that verify as yours.
